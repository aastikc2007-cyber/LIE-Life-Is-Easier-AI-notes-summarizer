# LIE – Life Is Easier

### AI Note Summarizer

**Team:** VajraUnit

LIE (Life Is Easier) is an AI-powered note summarizer designed to help users quickly extract key ideas from long notes, documents, or study material. The application simplifies reading by generating concise summaries, allowing users to save time and focus on important insights.

---

##  Features

* AI-powered note summarization
* Clean and responsive user interface
* Fast text processing
* Simple and intuitive workflow for students and professionals
* Built for productivity and efficient information consumption

---

##  Tech Stack

This project is built using:

* React
* Vite
* TypeScript
* Tailwind CSS
* shadcn/ui

---

##  Running the Project Locally

Make sure you have **Node.js and npm** installed.

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
```

Navigate to the project directory:

```bash
cd LIE-Life-Is-Easier
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The app will start locally and you can open it in your browser using the localhost link shown in the terminal.

##  Project Purpose

LIE was created to help users quickly understand large pieces of text by transforming them into short, meaningful summaries. It is especially useful for:
